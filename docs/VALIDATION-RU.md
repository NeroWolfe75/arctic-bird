# Проверка версии 0.3.16

Дата: 21 октября 2026 года.

В interface-icons.css добавлено адресное исключение для значка #showCustomHeaders.message-header-view-button .toolbarbutton-icon. Причина подтверждена по сохранённым ресурсам Betterbird: bullet-list.svg рисуется через context-fill, а общее правило темы задавало заливку с прозрачностью 80%.

В Chromium-модели с идентификатором, классами и inline-стилем штатной кнопки проверен CSS-каскад: обычный цвет #A3A9BB, hover/focus #E6E8EF, checked #8BC7FF, disabled с alpha 0.45. Fill-opacity равен 1; соседний значок сохраняет прежнюю 20%-ную заливку. Цвет подписи и размеры модели до/после совпадают. Chromium не проверяет передачу context-fill в SVG через XUL: нативная отрисовка Betterbird под Windows здесь не запускалась.

Все остальные рабочие CSS, включая карточки 0.3.15 и настройки пользователя, сохранены побайтно. В Preview.html изменена только подпись версии. Проверены целостность архива и отсутствие скриншотов в комплекте.

## Предыдущая проверка карточек 0.3.15

Дата: 20 октября 2026 года.

В mail-cards.css изменены две декларации: обычный фон — --f11-shell, обычный контур — 50% смеси --f11-line и --f11-paper. Все остальные рабочие CSS-файлы, включая переключатель чтения 0.3.14, settings.css, userChrome.css и userContent.css, сохранены побайтно. В Preview.html изменены только обычные фон/рамка карточек и подпись версии.

В Chromium использована прежняя модель с исходным threadPaneCardTemplate и CSS Betterbird 153.5.0esr-bb11. Сначала подключён модуль 0.3.13, затем обновлённый модуль; состояния сравнивались до/после.

Проверено:

- Обычный фон #101217. Контур вычислен как srgb(0.105882, 0.117647, 0.143137), около #1B1E25.
- Вычисленные фон, контур, размеры, скругления, shadow и outline при наведении и выборе совпадают с предыдущей версией.
- Обычные ширина/высота, толщина border 1 px и radius 8 px в тестовой модели сохранены.
- При входе с клавиатуры текущая карточка сохраняет голубой контур.
- Inline-фон аккаунта сохраняется, в том числе при выборе.
- Новый фон ограничен карточным режимом; при смене rows на thread-row переменные модуля не применяются. Область URL и медиапроверки доступности/печати не менялись.
- Preview.html открывается без ошибок JavaScript и показывает обновлённый фон. Модель просмотрена визуально.

Статически проверены CSS-импорты, изменения относительно архива 0.3.14, неизменность прежних CSS и обоих встроенных макетов чтения, целостность ZIP. Скриншоты в архив не включены.

Betterbird под Windows здесь не запускался. Модель проверяет каскад и геометрию на сохранённой разметке, но не нативную отрисовку Gecko. Размеры виртуальных строк, данные и обработчики не меняются.
