# Arctic Bird

Тёмная CSS-тема для **Betterbird и Thunderbird**: почти чёрные поверхности, тонкие разделители, монохромные значки и спокойный голубой акцент. Палитра основана на **Brackets Refined — Arctic для Zed**.

[English](README.md) · Версия **0.3.16** · Windows 11

![Тема Arctic: верхние вкладки, папки, карточки писем и область чтения](docs/images/arctic-overview.png)

*Обезличенная иллюстрация на основе снимка Betterbird. Все надписи, данные аккаунтов и содержимое письма заменены цветными полосками с помощью ИИ-редактирования. Изображение показывает компоновку и палитру, но не служит точным пиксельным эталоном. Для показанного вида включены скругления карточек.*

## Возможности

- Компактные вкладки у верхнего края окна; на широком окне поиск находится в той же строке.
- Единые фоны панелей, тонкие линии и согласованные цвета меню и кнопок.
- Мягкий фон и тусклый контур карточек писем; отчётливое наведение и выбор.
- Иерархия шапки письма: тема, имя отправителя, приглушённые служебные данные.
- Монохромные значки интерфейса и папок с сохранением цветных меток и значимых состояний.
- Общее оформление адресной книги, календаря, задач, настроек и окна создания письма.
- Один файл настроек и отдельные подключаемые CSS-модули.

Устанавливаемая тема состоит из CSS. Расширения и внедряемый JavaScript не требуются. HTML-макеты с локальными элементами управления предназначены для отдельного просмотра в браузере и в профиль почты не устанавливаются.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. В Betterbird или Thunderbird откройте **Справка → Информация для решения проблем → Папка профиля → Открыть папку**. Используйте нужный профиль приложения.
3. Откройте **Настройки → Основные → Редактор конфигурации** и установите `toolkit.legacyUserProfileCustomizations.stylesheets` в `true`.
4. Полностью закройте приложение. Сохраните резервную копию существующей папки `chrome`, если она есть.
5. Скопируйте папку **`chrome`** из проекта в профиль. Должны получиться пути `chrome/userChrome.css`, `chrome/userContent.css` и `chrome/fluent11/settings.css`.
6. Запустите приложение со встроенной системной темой.

Это оформление профиля через CSS, а не XPI-дополнение. При наличии другого пользовательского CSS объединяйте стили с учётом каскада и резервной копии.

## Настройка

Все параметры находятся в `chrome/fluent11/settings.css`. После изменения полностью перезапустите приложение. По умолчанию включена тёмная схема. Светлая палитра — дополнительный вариант, который не проходил такую же визуальную доводку, как Arctic.

Чтобы получить скруглённые карточки, как на иллюстрации, измените параметр внутри существующего блока `:root`:

```css
--f11-list-radius: 8px;
```

В поставляемом файле по умолчанию указано `0px`. Сам режим **«Карточки»** включается штатным меню списка писем. Высоту строк регулируйте настройкой плотности приложения.

| Элемент | Цвет Arctic |
| --- | --- |
| Основная поверхность | `#0D0E11` |
| Панели и поверхность карточек | `#101217` |
| Тусклый контур карточек | около `#1B1E25` |
| Разделители панелей | `#292E38` |
| Основной текст | `#E6E8EF` |
| Вторичный текст и значки | `#A3A9BB` |
| Акцент | `#8BC7FF` |

В браузере можно открыть [Preview.html](Preview.html) с редактором палитры и [Internal-Preview.html](Internal-Preview.html) с макетами внутренних страниц. Это демонстрационные макеты, а не работающий почтовый клиент. Редактор палитры не загружает существующий settings.css: перед использованием экспорта сохраните свои настройки.

## Обновление и удаление

Для обновления полностью закройте приложение, сохраните копию `chrome` и отдельно свой **`fluent11/settings.css`**. Замените папку `fluent11`, файлы `userChrome.css` и `userContent.css`, затем верните свой файл настроек и перезапустите приложение.

Для удаления закройте приложение и восстановите прежнюю папку `chrome`. Если прежнего оформления не было, удалите файлы темы. Перезапустите приложение.

## Совместимость и ограничения

Тема разрабатывалась с Betterbird под Windows 11. Селекторы сверены с ресурсами Windows-сборки **Betterbird 153.5.0esr-bb11** и исходниками **Thunderbird 158.0**. На других версиях и платформах может потребоваться подгонка. Часть изменений проверялась в браузерных моделях; подробности — в [совместимости](docs/COMPATIBILITY-RU.md) и [описании проверок](docs/VALIDATION-RU.md).

- Компактная верхняя строка рассчитана на горизонтальные вкладки. При ширине менее 1100 CSS px поиск переходит ниже. При необходимости отключите импорт `compact-header.css` в `userChrome.css`.
- Модуль `message-content.css` сохраняет фон области чтения в цветах темы. Штатный переключатель светлого/тёмного чтения поэтому может не возвращать обычный светлый фон. Для штатного поведения фона отключите этот импорт в `userContent.css`.
- CSS сохраняет штатные команды над письмом и не переносит их в меню **«Ещё»**.
- Страницы расширений, авторский HTML писем и некоторые закрытые компоненты могут сохранять собственные цвета. Тема не перекрашивает все элементы каждого письма в монохром.

## О проекте

Цветовой референс — Brackets Refined — Arctic для Zed. Штатные значки и элементы управления предоставляет почтовый клиент; проект меняет их CSS-оформление.

Независимый проект сообщества, не связанный с Thunderbird, Betterbird, Mozilla, Microsoft, Zed или Adobe и не одобренный ими. Названия продуктов принадлежат соответствующим владельцам.
